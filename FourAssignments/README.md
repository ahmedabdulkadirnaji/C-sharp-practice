# Four Windows Forms Assignments

This folder contains four C# Windows Forms exercises:
1. Hotel Booking System
2. Flight Booking System
3. Vehicle Rental Management System
4. Course Registration Fee System

## Run
Open FourAssignments.csproj in Visual Studio 2022 with the .NET desktop development workload installed, then press F5.

## Important assumptions
- The hotel handout's room names (Standard, Normal, Hight) do not exactly match the capacity names (Standard, Deluxe, Suite). This version maps Standard to 2 guests, Normal to 4, and Hight to 6.
- The flight handout does not provide a ticket price, so the form has an editable ticket-price field prefilled with $200 as an example. No excess-baggage charge was specified, so none is added.
- Controls are created in C# at runtime rather than using the drag-and-drop Designer.

Before submitting, test each form and make sure you can explain TryParse, if statements, switch, decimal calculations, validation, and ClearForm.
