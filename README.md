# Course Information
Course Title: Visual Programming (C#.NET)
Prerequisites: Programming
Instructor: Yahye Ali Isse

## Course Objectives
➤ This course incorporates the basic concepts of C# programming, problem solving and programming logic, 
as well as the design techniques of an object-oriented, event-driven languag
➤ A high priority is given to writing applications that are easy for the user to understand and to use.
➤ The course is rich in concise, practical, and real-world example programs, 
so the student not only learns how to use the various controls, constructs, and features of Visual C#,
but also learns why and when to use them

### Course Content
CHAPTER 1: Introduction to Visual C#
CHAPTER 2: Processing Data
CHAPTER 3: Making Decisions
CHAPTER 4: Loops, Files, and Random Numbers
CHAPTER 5: Modularizing Your Code with Methods
CHAPTER 6: Arrays and Lists
CHAPTER 7: ADO.NET
CHAPTER 8: Sample Project – Build Desktop Application
